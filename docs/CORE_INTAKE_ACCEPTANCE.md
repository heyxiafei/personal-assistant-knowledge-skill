# 核心资料读取与验收边界

四步上手 Preview 已提供先建私人骨架、读取获准资料填充、初步建议与选填表、补充后深入建议。安装没有自动执行钩子，由 Agent 在宿主支持的首次调用路径接续初始化。

## 三项核心状态

| 核心 | 当前状态 | 验收要求 |
| --- | --- | --- |
| Codex 完整历史 | 未完成账号全集验收 | 对明确主机、保留历史及截止时点全分页发现，逐条正文读取、去重和覆盖核对；近期列表或搜索不等于全集 |
| ChatGPT 完整历史 | 未完成账号全集验收 | 使用有完整枚举契约的正式入口，并分别核对正文、分支、附件和读取失败 |
| ChatGPT 完整个人记忆提供给 Codex | 未找到已验证的完整枚举契约 | 正式入口须有范围与完整性证据；摘要、定向搜索与推测不能替代 |

已有授权内的正式自动发现与读取优先；受阻时只问资料项目位置或必要的具体授权。用户自行导出是上述路径受阻后的末级兜底，须本人接受并在官方入口操作。代码支持导入不等于已完成真实账号验收。

## 独立运行时

app-server 适配器默认不启动真实程序。静态完整性、启动副作用、账号和输出范围必须单独核对，见 [运行时指南](CODEX_RUNTIME_PROBE.md)。不读取凭据、私有数据库或被拒绝的会话目录，不绕过安全控制。

## 本机与云端

本机、其他已连接主机、云任务、归档与 Codex 内的 ChatGPT 聊天分别记录可访问性和覆盖。云端安装不会自动获得本机历史或完整 Memory。无资料或某来源受阻时仍可建立已授权的空白骨架，并如实保留未知。

真实原文、附件、来源身份、游标、索引、设备诊断和个人状态只保留在用户授权的私人位置，不进入本仓库。公开报告只说明产品能力与验收边界。
