# Codex 运行时核查指南

本页提供通用核查流程，不公开任何用户设备的路径、安装版本、二进制摘要或诊断回执。具体运行结果保留在用户批准的私人目录。

优先使用宿主已经提供的正式只读历史入口。只有确需运行独立采集器时，才评估其运行时来源、完整性及启动副作用；找不到命令不能推断没有安装客户端，找到程序也不代表获准执行。

## 运行前核对

1. 核实用户选定程序的官方来源及适用的系统签名验证。异常时先区分检查环境与目标本身的问题，见 [签名核查](CODEX_SIGNATURE_DIAGNOSTICS.md)。不关闭安全设置、不修改签名或删除隔离属性。
2. 对照所选版本的 [官方 app-server 文档](https://learn.chatgpt.com/docs/app-server) 和 [公开源码](https://github.com/openai/codex/tree/main/codex-rs/app-server)。版本不同需要重新核对，不能用文档标题代替实际行为验证。
3. 明确账号、主机、历史范围和私人输出目标，并核对启动可能造成的状态库初始化、迁移、恢复、回填、日志和后台任务。前台 stdio 与客户端 RPC 白名单不保证 server 全局无写。
4. `thread/list` 的 `useStateDbOnly` 仅影响该列表请求。模型工具的只读沙箱也不能证明 server 自身只读。无法证明符合授权范围时，保留默认闭锁，继续使用已有正式只读入口。

原始诊断日志、程序摘要和具体本机配置只留在私人目标；公开交付只记录通用能力与未完成的验收项。不得把运行时发现或合成测试称为完整账号历史验收。
