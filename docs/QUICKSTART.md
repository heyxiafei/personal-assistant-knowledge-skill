# 个人助手 Skill：首次上手

先按 [安装与恢复](INSTALL.md) 选择草稿 PR 的已审阅提交 SHA，并安装到明确的项目级或用户级目录；也可直接使用该 SHA 的源码。需要 Python 3.9+。安装只复制通用 Skill，不读取账户或开始访谈；已有同名目录会停止并保留旧版。

显式读取所选安装目录的 `maintain-personal-context/SKILL.md`，或源码中的 `skills/maintain-personal-context/SKILL.md`，确认正在使用的目录与版本，再发送：

```text
用个人助手 Skill 帮我整理一份初稿。先读本次获准的资料，展示实际来源、时间范围和未覆盖项。
先预览“你是谁／你在做什么／你接下来做什么／建议”，允许未知或暂无建议。
承接已有答案，展示预填摘要，再只问仍缺或矛盾的内容，每轮一题、首轮最多八题。
我可用 A/B/C 选择，也可其他、自由补充、跳过、暂不确定、这项不保存、暂停或先用当前初稿。
我确认当前版本和目标后再保存。
确认前不创建或重写正式库，断点另经我允许再写；不要恢复暂停或取消的任务。
```

将允许读取的具体来源或项目、时间窗口一起说明；已经给过的范围无需重说。没有现成主档也可以开始。Skill 不因工具已连接就读取整个账号；只读到摘要、部分附件或有来源不可访问时会列出边界，不让你重填已知资料。

先展示可纠正初稿和预填摘要，再补影响当下协作的缺口。快速入门涵盖现状、近期目标、协作、约束、简介、能力、资源和协作边界；已知和已答不重问，全部已知可零题。首轮最多八题，随时可暂停或结束，助手已经可以使用当前初稿。后续只在你愿意时深入某个缺口，不需要先完成长访谈。

6–8 题、3–5 分钟是首轮作答的拟议设计目标，尚未通过真实用户计时验证，不是必答题数、完成时限或资料扫描承诺。这些问题用于了解实际背景与本次协作，不做人格测试或人格诊断。

客户端有原生选项工具时按实际能力展示候选；没有时提供相同内容的 A/B/C 文本选择，并接受直接文字回复。其他、自由补充、跳过、不确定、不保存、暂停续答始终可用，不默认替你选答案。安装不保证自动打开表单、弹窗或挂载页面。可用系统或客户端已有的语音转文字输入，先纠正识别结果再确认；此 Skill 不新增录音或转写服务。

预填摘要分别标记已有用户原话或自存资料、本轮明确确认、摘要或推测待核。候选不是你的答案，整体核对也不会自动确认推测。四段初稿继续把可靠事实、初步理解和待补分开并标来源；下一步与建议合计最多三条。纠正任何一项后，助手应同步相关项目和建议，再给更新版本。回答问题不等于同意入库；“这项不保存”会从保存计划和新断点中排除。

准备好后，可说：“把当前初稿中我确认的内容增量保存到这个私人目标：……”。确认绑定当前内容与指定目标；若本次已有足够明确的保存授权，助手沿用它，不重复问。保存前会读取原条目，保留手改、来源及纠错链，保存后读回；缺少目标工具会说明尚未保存，不拿本地草稿冒充云端完成。

默认不另存访谈文件。需要断点时先明确允许保存到公开源码与 Skill 之外的私人位置；下次核对断点与当前目标后续聊。整轮选择不保存则不新建或更新断点、导出和正式库；已有旧断点会如实告知，不会暗中删除。正式库事务失败按安装版 `references/local-helper.md` 的恢复流程处理，人工冲突仍需核对。

已有旧断点先按原格式核验，再在内存中迁移并承接原答案、来源和处理状态；不会要求重新填写，不自动沿用旧保存确认。已跳过或不保存的项目只留状态，后续深访不会自行重开。

流程细节见 [快速入门](../skills/maintain-personal-context/references/quick-start.md) 与 [共同保存规则](../skills/maintain-personal-context/references/first-interview.md)。候选提交、该提交的测试/CI 与真实用户验收分别核对；此说明不表示你的客户端已安装该版，或已经完成媒体、云端及跨会话真人验收。

## 本地合成示例

在源码根目录运行下列命令，只把合成资料的预览输出到终端，不写个人资料、断点或正式库：

```sh
python3 -B skills/maintain-personal-context/scripts/quick_start.py \
  --input tests/fixtures/quick-start.json --case new
```

该 helper 接收 Agent 已经读过并标注的资料，不自行读取 Codex、ChatGPT 或其他账户。真实试用先在对话中明确范围；没有额外文件保存授权时，直接在对话中使用流程。

## 离线补缺与下次继续

已授权保存可复用快照时，可让助手把实际已读来源和当前标注导出为私人会话包：`session.json`、五视图`result.md`和本地`session.html`。页面逐题提供选项与自由输入；未答保持空白，跳过、不确定和不保存不会伪装成事实。刷新前需显式下载回答，下载及读取成功都不代表已入正式库。浏览器须允许本地HTML，未实际打开时保留视觉/点击未验说明。

新会话先读取安装版Skill，再提供包路径和上次交付的`bundle_digest`；使用`session_bundle.py read --bundle 私人包路径 --expect-digest 上次值`校验后承接事实、来源边界与未答项。已有回答文件另按同一版本核验，由助手审核后承接，不假装重新问过或重新确认。旧包不包含新的保存授权，不重启暂停或取消项目。手改造成摘要不符时保留文件，核对后另导出新版本。旧离线包保持最多四题的原格式，不把快速入门八题直接作为旧包输入。实际 schema 和完整命令见 [会话包说明](../skills/maintain-personal-context/references/session-reuse.md)。
