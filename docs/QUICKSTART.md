# 个人助手 Skill：首次上手

先显式读取所选安装目录的 `maintain-personal-context/SKILL.md`，再发送：

```text
用个人助手 Skill 帮我整理一份初稿。先读本次获准的资料，展示实际来源、时间范围和未覆盖项。
先预览“你是谁／你在做什么／你接下来做什么／建议”，允许未知或暂无建议。
再只问仍缺或矛盾的内容，每轮一题，随答更新；我可自由输入、跳过、暂不确定或指定这项不保存。
我确认当前版本和目标后再保存。
确认前不创建或重写正式库，断点另经我允许再写；不要恢复暂停或取消的任务。
```

将允许读取的具体来源或项目、时间窗口一起说明；已经给过的范围无需重说。没有现成主档也可以开始。Skill 不因工具已连接就读取整个账号；只读到摘要、部分附件或有来源不可访问时会列出边界，不让你重填已知资料。

先展示可纠正初稿，再进入核心访谈；不需要先填完资料。最多四题，围绕现状、近期目标、约束和协作偏好，已知就跳过。客户端有原生选项工具时按实际能力展示选项，并接受自由回答；没有时直接文字一问一答，不会假装弹出原生界面。可用系统或客户端已有的语音转文字输入，先纠正识别结果再确认；此 Skill 不新增录音或转写服务。

四段初稿把可靠事实、初步理解和待补分开并标来源；下一步与建议合计最多三条。纠正任何一项后，助手应同步相关项目和建议，再给更新版本。回答问题不等于同意入库；“这项不保存”会从保存计划和新断点中排除。

准备好后，可说：“把当前初稿中我确认的内容增量保存到这个私人目标：……”。确认绑定当前内容与指定目标；若本次已有足够明确的保存授权，助手沿用它，不重复问。保存前会读取原条目，保留手改、来源及纠错链，保存后读回；缺少目标工具会说明尚未保存，不拿本地草稿冒充云端完成。

默认不另存访谈文件。需要断点时先明确允许保存到公开源码与 Skill 之外的私人位置；下次核对断点与当前目标后续聊。整轮选择不保存则不新建或更新断点、导出和正式库；已有旧断点会如实告知，不会暗中删除。正式库事务失败按安装版 `references/local-helper.md` 的恢复流程处理，人工冲突仍需核对。

流程细节见 [首次访谈](../skills/maintain-personal-context/references/first-interview.md)。本地候选流程与旧版本验收分开；此说明不表示新版已正式安装、公开上传或完成媒体/云端端到端验收。

## 离线补缺与下次继续

已授权保存可复用快照时，可让助手把实际已读来源和当前标注导出为私人会话包：`session.json`、五视图`result.md`和本地`session.html`。页面逐题提供选项与自由输入；未答保持空白，跳过、不确定和不保存不会伪装成事实。刷新前需显式下载回答，下载及读取成功都不代表已入正式库。浏览器须允许本地HTML，未实际打开时保留视觉/点击未验说明。

新会话先读取安装版Skill，再提供包路径和上次交付的`bundle_digest`；使用`session_bundle.py read --bundle 私人包路径 --expect-digest 上次值`校验后承接事实、来源边界与未答项。旧包不包含新的保存授权，不重启暂停或取消项目。手改造成摘要不符时保留文件，核对后另导出新版本。实际schema和完整命令见[会话包说明](../skills/maintain-personal-context/references/session-reuse.md)。
