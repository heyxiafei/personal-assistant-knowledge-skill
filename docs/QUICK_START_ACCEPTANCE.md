## 具体差异

- 新增 `scripts/quick_start.py`：从 Agent 已读标注生成有来源的预填；区分已有用户资料、本轮用户确认、摘要或推测待核。读取和语义判读仍由 Agent 在实际授权范围内完成，helper 不扫描账户。
- 首轮最多八个短题，已知或已答不重问，全部已知零题；已有 `current_problem` 可作为已审主线，不因缺另一个内部字段再问。立即提供可用初稿，允许随时暂停或结束，后续深访为可选缺口。
- 候选与来源绑定，无默认选择；支持自由输入、其他、跳过、不确定、不保存及 A/B/C 文本回退。有原生工具才按实际 schema 展示，不承诺弹窗或自动挂载。
- 复用 `interview.py` 的来源核对、纠正链、幂等提交、当前预览和确切保存计划绑定，以及 `space_state.py` 的断点 hash 与私人位置守卫。原脚本、旧四题格式和私人包 schema 未改。
- 旧访谈状态用 `migrate`；旧包先校验，再由 Agent 审核题目映射。答案转规范标注，控制动作经 `import_decisions` 承接，避免漏掉跳过或排除状态。迁移不继承保存确认，也不替换旧文件。
- “不保存”排除当前主题旧候选和正文、清除相关建议，阻止自动重新引入；自由文字回执中的逐字副本一并排除。最小状态只保留规范标注与必要回执字段，不携带未使用的原始历史载荷。语义改写、资料真实性和正式保存计划仍需 Agent 审核，不能据此宣称完整隐私审计。
- 普通“稍后补具体能力/资源”选择保留细节缺口；真实后续补充可关闭缺口。重复扫描标注与控制导入幂等，冲突不覆盖原状态。
- README、上手说明、Skill 入口及首次访谈路由改为默认快速入门，新增专用参考；新增四类完全合成输入及行为回归测试。

## 运行

在源码根目录显式读取 `skills/maintain-personal-context/SKILL.md`，可直接试用候选流程，无须覆盖正式安装。纯合成命令仅输出预览：

```sh
python3 -B skills/maintain-personal-context/scripts/quick_start.py \
  --input tests/fixtures/quick-start.json --case new
```

`--case` 另有 `existing`、`all_known`、`conflict`。真实资料默认在当前获准对话中使用；另存输入、断点或导出须有相应文件保存授权并位于源码与 Skill 之外。

针对性测试和完整测试：

```sh
python3 -B -m unittest discover -s tests -p test_quick_start.py -v
SESSION_BUNDLE_NODE=/absolute/path/to/node python3 -B -m unittest discover -s tests -v
python3 -B scripts/check_package.py
git diff --check
```

Node 仅用于旧离线 HTML 的可选 DOM 执行测试，Python helper 本身只依赖标准库。
