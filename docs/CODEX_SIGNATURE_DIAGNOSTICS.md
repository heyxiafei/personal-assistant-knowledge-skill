# 运行时签名核查指南

本页不包含真实设备检查结果。对用户明确选定的程序，使用操作系统正式支持的静态验证方式，并将目标、结果与退出码留在获准的私人位置。

签名显示信息、文件摘要自洽和系统信任验证是不同证据；任何一种都不能单独证明程序启动没有副作用。若检查返回异常，可用可信系统样本判断检查环境是否正常，再决定是否需要官方支持。系统样本也失败时，不直接断定目标应用已损坏。

不绕过系统安全警告、不重签、不修改信任设置、不删除隔离属性。静态验证通过也不自动授权运行；后续仍按 [运行时核查](CODEX_RUNTIME_PROBE.md) 评估数据读写与后台任务。

诊断的实际应用位置、版本、二进制摘要和原始输出不进入公开源码或发布文件。用户需要分享具体回执时，先明确分享范围与接收方。
