
## 安装、使用和恢复

完整源码包解压后，选一个新的隔离项目，用已有安装器：

```sh
PROJECT="/absolute/path/to/chosen-project"
python3 -B scripts/install.py install --dest "$PROJECT/.agents/skills"
```

已有同名安装拒绝覆盖。只含 Skill 的压缩包也可解压出 `maintain-personal-context` 文件夹放入所选项目 `.agents/skills`，先确认该位置不存在同名目录；这种手工安装没有本包安装标记。安装不建库、不扫描、不增加连接或权限。

在该项目显式读取 `.agents/skills/maintain-personal-context/SKILL.md` 后，例如：“使用这个 Skill，把这些获准附件和原话补充进现有私人资料库。先报告实际读取范围；保留来源、未知、手改和取消状态。事实、关联推断、可选建议分开。只按我指定的本地/私人目标保存。”目标仍是 Space 而工具不可用时，明确未保存到 Space；本地草稿不会代替目标完成。
