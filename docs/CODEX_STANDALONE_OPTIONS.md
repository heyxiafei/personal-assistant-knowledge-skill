# 独立 Codex 运行时的选择边界

独立运行时是用户明确选择后的可选方案，不是首次使用 Skill 的要求。已有宿主正式只读入口可用时，优先复用它们。

安装方式以 [OpenAI 官方仓库](https://github.com/openai/codex) 的当前说明为准。固定明确版本、核验官方资产和适用系统签名；安装器、包管理器可能写缓存、命令链接或配置，也可能运行安装脚本。下载、安装、运行分别核对授权，不为读取历史自动安装或升级软件。

程序安装目录与账户数据目录不是同一边界。独立程序可能仍访问既有状态；空数据目录也不会自动包含过去历史。不要复制凭据、数据库或会话目录来绕过正式读取入口。

即使运行时来源可信，app-server 启动仍需核对数据库初始化或迁移、历史元数据回填、日志、模型刷新、插件及远程连接行为。没有符合当前授权范围的正式读取方式时，保持默认闭锁；不把内部测试开关包装成正式只读方案。

具体设备、版本和检查结果只保留在用户选定的私人位置。下一步按 [运行时核查指南](CODEX_RUNTIME_PROBE.md) 逐项处理，不将安装成功当成全历史采集成功。
